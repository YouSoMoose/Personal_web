# Akhil Khanna Tumati

Personal website: https://akhil-tumati.github.io/

## Files

- `index.html` — page content and links
- `css/styles.css` — layout, typography, responsive styling, and cursor appearance
- `js/script.js` — decorative fireflies
- `assets/images/` — portrait
- `assets/icons/` — favicon and cursor artwork
- `assets/documents/` — resume PDF
- `scripts/serve.js` — local preview server

## Preview locally

With Node.js installed, run `npm start` and open http://127.0.0.1:4173.
No packages or build step are required.

## Publishing

GitHub Pages serves the `main` branch from its root directory. The repository
is named `akhil-tumati.github.io`, so the website lives at the account's home URL
rather than a project subdirectory.
